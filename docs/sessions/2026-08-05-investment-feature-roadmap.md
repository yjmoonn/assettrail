# 투자 기능 로드맵 TODO 확정

## 목적

AssetTrail을 자산 기록 도구에서 투자 의사결정 운영체계로 확장하기 위한 기능을
1~5단계의 실행 가능한 TODO와 완료 기준으로 관리한다.

## 핵심 결정

- 의사결정 센터와 기본 집중도 분석을 먼저 제공한다.
- 신규자금 우선 배분과 수동 위험 태그를 두 번째 단계로 둔다.
- 거래·현금흐름 원장은 기반 1순위지만 마이그레이션 위험을 고려해 세 번째 단계에서
  구현하고, 데이터 모델 설계는 첫 단계부터 병행한다.
- 정확한 성과 분석은 거래 원장 이후에만 제공한다.
- 외부 데이터와 AI는 구조화된 데이터·인증·보안 검증 이후에 연결한다.
- PR #6은 전체 병합하지 않고 결정론적 분석 로직만 최신 `main` 위에 선별 이식한다.

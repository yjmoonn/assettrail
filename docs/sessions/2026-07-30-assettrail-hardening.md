# AssetTrail 안정화 1~5단계

## 목적

운영 `main`을 기준으로 계산 정확성, 장기 데이터 내구성, 가격·배포 안전성,
모바일 사용성과 접근성을 한 번에 점검하고 자동 회귀 테스트로 고정한다.

## 핵심 결정

- 대규모 초안 PR #6은 안정화 작업과 합치지 않고 별도로 유지한다.
- 사용자 저장 형식은 `schemaVersion: 2`, 클라우드 동시성은 revision으로 관리한다.
- 충돌은 자동 최신값 선택 대신 사용자가 가져오기·올리기·나중에 중 선택한다.
- 가격과 종목 디렉터리를 분리하고 심볼 실패가 가격 계산을 실패시키지 않게 한다.
- 빈 가격표나 품질 미달 가격표를 배포하는 것보다 기존 운영 배포를 유지한다.
- Firestore의 비신뢰 가격 요청은 사용하지 않고 `tickers.json`만 가격 입력으로
  신뢰한다.

## 변경

- 은퇴 프리셋, 스냅샷 안전 조건, US 손익 설명, 핵심 입력 범위를 바로잡았다.
- compact snapshot, legacy 마이그레이션, 가져오기 검증·자동 백업, 저장 실패 안내,
  가져오기 저장 실패 롤백, 클라우드 크기·revision 방어를 추가했다.
- 커스텀 충돌 대화상자와 충돌 보류 중 자동 업로드 차단을 추가했다.
- `prices.json`/`symbols.json` 분리, 실제 거래일 품질 게이트, 원자적 교체, 배포
  재사용 실패 안전 경로를 추가했다.
- 공유 가격 요청을 앱과 생성기에서 제거하고 `priceRequests/**`를 전면 차단했다.
- Firestore Rules를 허용 경로 중심으로 제한하고 CI 권한·테스트·감사를 보강했다.
- 모바일 목표/포트폴리오 단계 탐색, 키보드 탭 이동, 드로어 포커스,
  표·차트 대체 정보, 숨김 안전 DPR 대응 차트와 44px 터치 대상을 추가했다.

## 검증

- JS 앱·가격·심볼·클라우드·충돌·데이터 회귀 테스트 통과.
- Python 가격 생성기 테스트 통과.
- Firestore Emulator Rules 테스트 통과.
- `npm audit --audit-level=high`, YAML 파싱, Python 구문, `git diff --check` 통과.
- Chrome 1440px, 1280px, 390px, 430px 및 충돌 대화상자 실화면 확인.
- 운영 가격 파일 기준 초기 가격 파일 약 3.18MB에서 0.76MB로 감소 확인.

# 투자 기능 2단계 — 행동 지원

## 목적

기존 자산을 불필요하게 매도하지 않고 신규자금으로 자산군 비중을 조정하며, 외부
데이터 없이도 수동 위험 태그로 공통 노출과 위험예산을 점검할 수 있게 한다.

## 핵심 결정

- 신규자금 결과는 국내·해외·현금·수동 자산군별 검토 예산만 제공한다. 특정 종목,
  주문, 가격과 수수료는 결정하지 않는다.
- 배분은 최소 부족 → 목표 부족 → 최대 여유 순서이며 원 단위 총액과 모든 밴드
  제약을 동시에 만족해야 한다. 불가능하면 부분안을 만들지 않는다.
- 신규자금은 1원 단위 안전 정수만 허용하고 시장 자산 평가금액이 누락되면 불완전한
  총액으로 계산하지 않는다. 목표 합계 표시 오차와 수학적인 최소·최대 합계 제약의
  허용오차는 분리한다.
- 계산 결과는 저장하지 않고 정책과 신규자금 입력만 저장해 현재 평가금액으로 다시
  계산한다.
- 시장 종목의 위험 태그는 같은 정규화 티커의 모든 계좌가 공유한다. CASH·MANUAL은
  자산별 태그를 사용한다.
- 태그 노출은 연결된 경제적 포지션의 전체 평가금액이다. 한 포지션이 여러 태그에
  포함될 수 있으므로 태그 금액과 차원별 비중은 비가산이다.
- 위성 위험예산은 `STRUCTURAL_GROWTH`, `CYCLE`, `TACTICAL`을 포함한다.
  `SURVIVAL`은 별도 역할로 유지한다. AI 구조적 성장과 사이클은 위성과 중복 가능한
  오버레이다.

## 변경

- `action-engine.js`: 결정론적 신규자금 배분과 위험 태그·위험예산 분석을 추가했다.
- `app.js`, `index.html`, `styles.css`: 자산군 비중 밴드, 신규자금 폼·결과, 위험예산,
  수동 노출 지도와 자산 상세의 7차원 태그 편집을 추가했다.
- 저장 스키마를 v4로 올리고 `policyProfile`, `contributionPlan`, `riskTags`를 로컬·
  클라우드·가져오기·내보내기·충돌 fingerprint에 포함했다.
- `tests/action-engine.test.mjs`, `tests/app-action-support.test.mjs`와 기존 데이터·
  클라우드 회귀 테스트를 갱신했다.
- Pages 배포가 `action-engine.js`와 행동 지원 테스트를 포함하도록 워크플로를
  갱신했다.
- README, 아키텍처, 테스트 가이드, 활성 TODO와 핸드오프 노트를 v4 동작에 맞췄다.

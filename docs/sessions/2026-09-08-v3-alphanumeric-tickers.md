# V3 영숫자 KRX 코드 누락 수정

## 목적
조회 기록에는 존재하지만 V3 패키지에서 빠지는 영숫자 KRX 종목을 보존한다.

## 핵심 결정
- 앱의 기존 `[0-9A-Z]{6}` 계약에 export 검증을 맞춘다. 스키마와 원장·조회 기록을 변경하지 않는다.
- 실제 자료는 Git에 포함하지 않고 공개 테스트는 합성 fixture만 사용한다.

## 변경
- export builder 및 validator가 사용하는 KRX 정규식 수정.
- 정상 숫자·영숫자·소문자 정규화, 평가 합계 보존 및 잘못된 코드 거부 회귀 테스트 추가.

## 검증
- JavaScript 문법 검사와 AI export 순수 엔진·앱 통합 테스트 통과.
- 별도 비공개 저장 기록으로 누락 재현 및 수정 후 합계 보존과 소비자 계약 호환성 확인. 로컬 재생성은 운영 export 성공으로 취급하지 않는다.

## 다음 작업
- 전체 테스트와 PR CI 결과 확인.
- 사용자 승인 후 병합·Pages 배포 및 같은 저장 기록의 운영 V3 재내보내기 검증. 추가 조회 기록 저장은 필요 없다.

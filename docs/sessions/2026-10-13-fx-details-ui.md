# 반복 환율 배너 제거

## 목적
정상 저장 가능한 지연 환율에 대해 사용자가 요청한 긴 노란 문구 제거를 반영한다.

## 핵심 결정
- 전체 화면 공통 배너와 자산 가격 알림의 중복 문구를 모두 제거한다.
- 저장 성공 안내는 성공/되돌리기만 표시하고 환율 근거는 설정의 접힌 상세정보에 둔다.
- 지연/잠정 메타데이터, 과거 기록, 원장, 권한 검사와 실제 오류는 유지한다.

## 변경
- `fxValuationNotice`는 실제 환율이 없을 때만 표시한다.
- `priceAlert`와 운영 요약의 경고색에서 유효한 지연 환율만 제외한다.
- 설정 가격표 카드에 환율 상세를 추가해 값·실제 기준일·출처·조회시각·상태·기대일을 표시한다.
- quick snapshot/월간 점검의 성공 메시지에 붙이던 반복 안내만 제거한다. qualityIssues와 valuation 데이터는 그대로 저장한다.

## 검증
- 지연/장기 지연에서 두 알림 숨김, 상세 근거 및 저장 성공 메시지 확인과 비정상 FX 오류 유지 회귀검사를 추가했다.
- 기존 Chromium+Firestore Emulator 검증에 1440/1280/390/430px의 홈·자산·기록·목표·설정에서 긴 배너 없음과 상세 펼치기 검사를 추가했다.
- 실제 저장·재조회·과거 불변·비소유자 거부 검증은 유지한다. 개인 계정 쓰기와 인증서 경고 우회는 하지 않는다.

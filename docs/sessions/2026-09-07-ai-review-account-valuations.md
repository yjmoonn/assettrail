# AI 점검 계좌별 평가정보 추가

## 목적

가장 최근 조회 기록의 평가 근거를 계좌별로 재현하고, AI 점검 패키지에서 일반계좌와
ISA를 구분해 각 계좌의 종목 수량과 평가액을 확인할 수 있게 한다.

## 핵심 결정

- 주 상태는 `schemaVersion: 9`, 신규 조회 기록은
  `assettrail.snapshot-valuation.v2`를 사용한다.
- 평가내역에는 저장 당시 사용자가 입력한 `accountName`을 보존하고 `AUTO` 계좌분류에서
  ISA를 일반계좌와 분리한다.
- AI 계약은 `ASSETTRAIL_AI_REVIEW_V3`, 고정 지침은
  `ASSETTRAIL_MONTHLY_REVIEW_PROMPT_V3`를 사용한다.
- 계좌명이 없는 v1 평가내역은 현재 자산과 결합해 과거 이름을 추정하지 않고
  `MISSING_SNAPSHOT_ACCOUNT_NAMES`로 계좌별 판단을 유보하고 재저장을 안내한다.
- 계좌명은 수동 내보내기에 포함하지만 앱이 외부 AI로 자동 전송하지 않는다. 계좌명에
  계좌번호·이메일 등 민감정보가 있으면 사용자가 수정하고 조회 기록을 다시 저장한 뒤
  첨부해야 한다.

## 변경

- 같은 종목도 계좌가 다르면 AI 점검 포지션을 분리하고 계좌별 수량·확정 종가·환율·
  원화 평가액과 `accountName`을 제공하도록 저장·내보내기 계약을 확장했다.
- UID·이메일, 내부 자산·거래 ID, 원거래와 자유 메모 제외 계약은 유지했다.
- 설정 화면, README, 아키텍처·외부 데이터·테스트·핸드오프 문서를 V3/v9 기준으로
  갱신하고 계좌명 민감정보 경고를 추가했다.

## 검증

- Python 3.13 의존성과 Java 21을 사용한 `npm test` 전체 검증을 통과했다. AI 내보내기,
  가격, 데이터 마이그레이션, 히스토리, 클라우드와 Firestore Rules가 모두 포함된다.
- PR 전체 CI를 통과한 뒤 main에 병합하고, Pages의 V3/v9 캐시 키와 실제 계좌별
  Markdown 내보내기를 확인한다.

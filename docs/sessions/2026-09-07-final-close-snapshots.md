# 저장 시 최신 확정 종가 적용

## 배경

- 조회 기록 저장은 화면에 이미 적재된 가격표를 그대로 사용해 저장 직전 가격 갱신 실패를 알 수 없었다.
- 국내 가격 수집기의 `closePrice`는 장중에도 현재가를 반환하지만, 기존 산출물은 이를 종가처럼 저장했다.
- 조회 기록에는 총액과 유형별 합계만 있어 저장 당시의 종목별 수량·적용가격·평가액을 사후 검증할 수 없었다.

## 계약

- 가격 생성기는 장중 행을 제외하고 각 시장의 최근 완료 세션만 `FINAL_CLOSE`로 인증한다.
- 가격 산출물은 시장별 다음 마감 시각까지의 인증 유효시간을 제공한다. 앱은 실제 보유 시장만 확인하며, 해당 인증이 만료됐거나 확인되지 않은 가격표로는 조회 기록을 저장하지 않는다.
- 조회 기록 저장 직전에 캐시를 우회해 가격표를 다시 내려받는다. 재조회 실패 시 기존 메모리 가격으로 우회 저장하지 않는다.
- 조회 기록에는 `assettrail.snapshot-valuation.v1` 평가 근거를 함께 저장한다. 양수 수량의 시장 자산과 CASH·MANUAL 자산의 유효 계좌분류와 원화 평가액, 시장 자산의 수량·확정 종가·가격일, 미국 자산의 환율·환율일을 포함한다. 시장 자산이 없으면 `MANUAL_AMOUNT_ONLY`로 가격표 미사용을 명시한다.
- 과거 조회 기록에는 현재 가격을 소급 적용하지 않는다.

## 운영

- 가격 배포는 미국 조기·정규장과 Yahoo 원화 환율의 런던 서머타임·표준시 마감을 포괄하는 02:20·03:20·05:20·06:20·08:20·09:20 KST와 국내 정규장·지연 개장 특수일을 포괄하는 평일 15:45·16:40 KST에 확인한다.
- 환율 완료 세션은 `KRW=X` 일봉 날짜로 추정하지 않고 Yahoo chart metadata의 `exchangeTimezoneName`과 `currentTradingPeriod.regular`로 확인한다. 마지막 포함 minute 다음 시각부터 15분을 더 기다리며 세션 rollover 직후에도 직전일을 조기 인증하지 않는다.
- PR 테스트, main 병합, Pages 배포, 운영 `prices.json` 계약과 실제 저장 동작을 모두 확인한 뒤 완료로 본다.

# 미국 보유종목 가격 커버리지 복구

## 목적

미국 보유종목 가격 누락으로 총자산 계산과 조회 기록 저장이 차단되는 문제를 해결한다.

## 핵심 결정

- 가격 생성 대상은 기존 보안 경계대로 리뷰 가능한 `tickers.json`에서만 관리한다.
- 현재 누락된 9개 미국 보유 티커를 명시적으로 추가하고 회귀 테스트로 고정한다.

## 변경

- MU, AVGO, BE, SNDK, ADI, NVDA, WDC, INTC, COHR를 US 가격 대상에 추가했다.
- 실제 가격 생성으로 모든 요청 종목의 가격과 가격일을 확인했다.

## 검증

- 로컬 실가격 생성: KRX 4,303건, US 24/24, 오류 0건
- `.venv` 기준 `npm run test:price-requests`: 통과

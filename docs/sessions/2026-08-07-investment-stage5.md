# 투자 기능 5단계 — 외부 데이터와 AI 로컬 안전 기반

## 목적

1~4단계의 구조화된 포트폴리오·원장·성과를 바탕으로 기업 실적과 ETF 구성종목을
보강하고, 개인정보와 비용 경계를 넘지 않는 검증 가능한 보고 흐름을 만든다.

## 핵심 결정

- Butler는 공식 개발자 API·자동 이용·재배포 권한을 확인하지 못한 상태에서 자동화하지
  않는다. 사용자가 공식 화면의 재무정보 표를 복사해 붙여넣는 `BUTLER_MANUAL`·
  `USER_SUPPLIED`·`SECONDARY_AGGREGATOR` 입력만 지원한다.
- 붙여넣은 원문은 저장하지 않는다. 허용된 기업 사실, 확정치/컨센서스, 출처·기준일·
  커버리지·revision만 사용자별 별도 로컬 저장소에 보관한다.
- ETF 구성종목은 사용자가 제공했거나 재배포가 허용된 `PHYSICAL_LONG_ONLY` 카탈로그만
  사용한다. 직접·간접 중복노출과 현금·미매핑·미보고·미지원 비중을 함께 계산하고
  출처나 항등식을 검증할 수 없으면 실패 상태로 제한한다.
- AI 입력에는 상대 비중·수익률·상태와 불투명 근거 ID만 넣는다. 개별 Butler 기업
  비율은 시장 전체 수치로 오인되지 않도록 카드에만 표시하고 AI 입력에는 가용 상태만
  넣는다. 기본 보고서는
  결정론 규칙으로 만들고, ChatGPT 해석은 사용자의 수동 JSON 전달과 반환 검증으로만
  제공한다.
- 앱은 API 키, 모델 네트워크 호출과 자동 주문을 포함하지 않는다. ChatGPT Pro를
  커스텀 앱 API 인증으로 재사용하거나 별도 비용 방식으로 자동 전환하지 않는다.
- PR #6은 최신 인증·보안·데이터 모델과 맞지 않는 부분을 전체 병합하지 않는다.

## 변경

- `external-data-engine.js`와 분석 화면에 Butler TSV 미리보기·정규화·revision 병합을
  추가했다.
- `etf-exposure-engine.js`와 분석 화면에 카탈로그 검증, 표준 종목 ID, 중첩 ETF와
  직접·간접 경제적 노출 집계를 추가했다.
- `ai-report-engine.js`와 분석 화면에 근거 envelope, 결정론 보고서, 수동 ChatGPT
  handoff 다운로드/복사와 반환 JSON 검증을 추가했다.
- 기업 스냅샷과 ETF 카탈로그를 v6 주 상태·Firestore와 분리된 사용자별 로컬 키로
  저장하고 크기·개수 한도, 별도 백업·비우기와 손상 원본 쓰기 차단을 적용했다.
- ETF 입력·확장 수 상한, HTTPS 무자격증명 URL, 14일 기준일 오래됨, 카탈로그 누락 ETF
  원금 보존을 적용했다.
- Butler·ETF 출처 조회 시각을 필수로 하고 5분을 초과한 미래 조회 시각과 미래
  확정치를 거부하되 미래 컨센서스는 허용했다. `instrumentKind`가 명시된 중첩 펀드
  누락과 주식·펀드 ID 충돌은 추정 확장하지 않고 `UNSUPPORTED` 또는 `LIMITED`로
  낮춘다.
- AI 보고서 항목을 exact fact ID와 근거 합집합에 결속하고 계산·해석 문구를 승인된
  템플릿으로 제한했다. 검증 성과 근거는 최신 평가점이 7일을 넘으면 `STALE`로 낮춘다.
- 보조 저장소는 다른 탭의 원문 변경을 저장 직전 차단하고 `storage` 이벤트로 다시
  읽는다. 사용자 전환 때 Stage 5 입력과 결과 DOM을 지우고 진행 중인 파일 읽기도
  취소한다. 같은 저장소를 비우는 동안 대기 중인 가져오기도 무효화한다. 외부 백업
  복원·스냅샷 삭제 전 백업과 ETF 교체 전 백업을 제공한다.
- `scripts/manage_us_tickers.mjs`에 US 가격 대상 review와 명시적 `--apply` 흐름을
  추가했다.
- 배포 파일 목록, 테스트 스크립트와 사용자·아키텍처·테스트·핸드오프 문서를 5단계
  경계에 맞췄다.

## 검증

- 순수 엔진 테스트는 Butler 원문 비저장·확정/컨센서스 분리·출처/revision/URL 정규화,
  ETF 라이선스·구조·중복·순환·과부하 상한·항등식, AI 개인정보 제거·digest·정확한
  fact 결속·응답 거부 계약을 확인한다.
- 앱 연결 테스트는 사용자별 로컬 저장 격리, 클라우드 비포함, 실패 상태와 분석 화면
  연결을 확인한다.
- 필수 명령은 `npm run test:external-data`, `npm run test:etf`, `npm run test:ai`,
  `npm run test:stage5`, `npm test`다. 실제 실행 결과와 데스크톱·모바일 확인 여부는
  이 작업의 최종 보고를 기준으로 한다.
- 일반 테스트와 Mock에는 외부 사이트·모델 호출이 없으며 API 키와 ChatGPT 로그인이
  필요하지 않다.

## 남은 작업

- OpenDART·SEC Company Facts 운영 수집기는 약관, 서버 캐시, 속도 제한, 마지막 정상
  데이터, 장애 상태와 식별자 매핑을 설계한 뒤 추가한다.
- Butler 자동 연동은 공식 개발자 API·자동 이용·저장·재배포 권한이 확인된 경우에만
  검토한다. 현재 세션이나 쿠키를 자동화에 재사용하지 않는다.
- 재배포가 허용된 ETF 공급자와 정기 갱신 정책을 선정한다.
- 자동 AI는 Auth·App Check·서버 최신 revision 검증·Secret Manager·사용량 제한과
  별도 모델 비용 승인이 갖춰진 callable 백엔드로만 추가한다.
- 클라우드 분석 저장을 추가할 때 다른 사용자의 데이터·보고서 접근 차단을 Rules와
  실제 E2E로 검증한다.

# Butler 가져오기 품질 판정 수정

## 목적
Butler에서 그대로 복사한 손익계산서가 누락·미지원·부분 상태처럼 보이는 문제를 해결한다.

## 핵심 결정
- 값이 없는 미래 기간은 저장 범위가 아니므로 누락으로 보지 않는다.
- 정상적인 재무 상세 행은 저장하지 않더라도 알 수 없는 입력으로 경고하지 않는다.
- 미리보기는 저장 전 핵심 실적과 저장 범위를 확인하는 화면으로 정의한다.

## 변경
- `external-data-engine.js`의 누락·상세 행·커버리지 판정을 수정했다.
- `app.js` 미리보기를 저장 예정 기간·핵심 지표·수치 중심으로 단순화했다.
- 실제 Butler 형식과 미래 빈 열을 회귀 테스트에 추가했다.

## 검증
- 공유된 원본이 38개 기간·3개 핵심 지표·114개 수치, 누락 0·미지원 0으로 파싱됨을 확인했다.
- JavaScript 문법, 외부 데이터, 분석 화면, 데이터 내구성 테스트가 통과했다.
- 1440·1280·430·390px 실제 화면에서 미리보기 내용과 가로 넘침 없음을 확인했다.
- 전체 테스트는 가격 품질까지 통과했고 로컬 Java 부재로 Firestore Rules 단계만 실행하지 못했다.

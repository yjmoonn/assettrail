# 조회 기록 가격 인증 반복 만료

## 목적

KRX 최신 확정 종가 인증 유효기간이 지난 순간 조회 기록 저장이 막히는 반복 문제의 원인을 고치고, 갱신 장애 시 자동 복구 경로를 제공한다.

## 핵심 결정

- 만료 검사는 유지한다. 확인되지 않은 가격으로 기록을 저장하지 않는다.
- 기존의 로그인 제한 가격 최신화 요청을 저장 흐름에서 재사용한다. 생성 실패, 권한 부족, 저장 중 데이터 변경은 계속 저장을 막는다.
- 데이터 갱신 예약·수동 실행에는 전체 앱 테스트를 반복하지 않고 가격 생성 품질 검사만 유지한다. 코드 변경은 기존 전체 CI를 통과해야 한다.
- 인증서 전체 만료 시각이 미래더라도 보유 시장별 만료 시각이 이미 지났으면 갱신을 요청한다. KRX와 FX처럼 시장별 유효기간이 다른 경우를 포함한다.

## 변경

- 가격 인증 만료가 확인되면 저장이 최신 가격 생성을 요청하고, 새 `prices.json`을 읽은 다음 인증과 저장 상태를 다시 검사한다.
- 가격 생성 대기 중 성과 평가점을 중복 갱신하지 않는다. 실제 저장은 갱신 뒤 같은 기존 저장 흐름에서 진행한다.
- 인증 만료, 최신화 권한 부족, 10분 시간 초과를 구분해 조치 방법을 안내한다.
- 인증 만료 시각은 KRX 정상 마감 후 10분인 15:40 KST인데 기존 예약은 15:45 KST였고, 가격 생성 전에 전체 테스트 잡을 기다려 반복 공백이 생겼다. 예약 시각을 15:40 KST로 옮기고 데이터 전용 실행은 전체 테스트를 건너뛰게 했다.
- 가격 생성 실패는 30초 간격으로 최대 3회 재시도한다. 완전한 가격표 품질 검사가 통과하지 않으면 배포하지 않는다.

## 검증

- 운영 `prices.json`과 GitHub Actions 최근 실행을 읽기 전용으로 확인했다. 최신 가격표는 2026-10-08 14:04 UTC 생성, KRX 세션은 2026-10-08, KRX 인증 만료는 2026-10-12 06:40 UTC였다. 직전 예약 실행 중 가격 생성 실패가 있었고, 뒤이은 예약 실행은 성공했다.
- 최근 실행에서 `Generate prices` 단계가 실패한 예약 run 두 개를 확인했다. GitHub Actions 로그 다운로드가 네트워크에서 거부되어 공급자 측의 구체적인 실패 원인은 확인하지 못했다.
- `npm test`가 종료 코드 0으로 끝났다. 여기에는 JS 문법, 전체 앱 회귀, 자동화된 가격 생성기 테스트, Firestore Emulator 규칙 테스트가 포함된다. Emulator의 `PERMISSION_DENIED` 출력은 거부를 기대하는 규칙 테스트에서 정상으로 발생했다.
- 가격 저장 회귀 테스트는 만료된 보유 KRX 인증에서 갱신 workflow 요청, 새 `prices.json` 로드, 갱신 가격 기준 총액 저장을 검증한다. 전체 인증 만료 시각이 미래이고 KRX 시각만 만료된 상황도 포함하며, 요청 실패나 로그인 부족이면 저장하지 않는 것도 확인한다.
- `test:workflow`는 KRX 15:40 예약, 가격 생성 재시도, 데이터 전용 경로의 테스트 생략과 코드 변경 CI 조건을 고정한다.
- PR CI, main 병합 및 Pages 배포 후 라이브 산출물을 검증해야 한다. 개인 운영 Firebase 기록은 수정하지 않고, 배포된 앱 파일과 실 가격표를 대상으로 격리된 테스트 데이터로 저장 흐름을 smoke test한다.

## 다음 작업

- PR 전체 CI를 통과시키고 main에 병합한다. Pages 배포 후 라이브 앱/가격표를 읽고, 격리된 저장 smoke test가 배포 파일에서 성공하는지 확인한다. 예약 실행이 만료 시각 직후 가격표를 갱신하는지는 다음 KRX 영업일 run에서 확인한다.

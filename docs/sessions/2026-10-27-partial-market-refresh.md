# 시장별 가격 부분 갱신

## 목적
US 기준일 불일치 등 한 시장의 지연이 정상 주식·환율 발행까지 막는 문제를 해결한다.

## 핵심 결정
- 기존 공급자·완료 세션 캘린더·종가 선택 로직을 유지한다. 인증 유효기간은 늘리지 않는다.
- 시장별 CURRENT/DELAYED/MISSING과 실제 날짜별 개수·기대 세션을 발행한다. 지연 시장의 인증 세션과 만료는 비우고 전체는 PARTIAL_FINAL_CLOSE로 구분한다.
- 유효한 수집 종가와 이전 발행값 중 더 최근 값을 보존한다. 잘못된 식별자·금액·날짜·미확정값은 제외한다. 이전 값이 없어도 다른 정상 시장은 발행하고, 모든 값이 없으면 실패한다.
- 지연 주식은 현재 금액 미리보기만 허용하고 확정 조회기록·성과 평가점은 차단한다. 기존 지연 FX 조회기록 정책과 과거 기록은 유지한다.

## 변경
- 생성기: 시장별 부분 품질 검사, 이전 파일 fallback, 수집일/발행일별 종목 수 로그, 상태 메타데이터 직렬화.
- workflow: 생성 전 운영 가격표를 읽어 fallback으로 사용. FX 확정 이후 10:20/11:20 KST 두 번 추가 예약. 기존 3회 재시도·코드 CI·main 배포 조건 유지.
- 앱: 상태 영역에 지연 시장과 실제 기준일 표시. US 지연을 환율 지연으로 오인하지 않도록 시장별 상태 사용. UI 구조·저장 스키마·보안 규칙은 변경하지 않는다.

## 검증
- `PATH="$PWD/.venv/bin:$PATH" npm test`: 전체 통과, Firestore Emulator 종료 코드 0.
- 후속 보완 후 `npm run check:js`, `npm run test:prices`, `npm run test:price-requests` 재검증 통과.
- 정상/한 시장 실패/FX 지연/이전값 없음/잘못된 금액·날짜·식별자/복구/부분 상태의 실제 파일 발행 회귀 검증.
- 격리 Chromium 1440/1280/390/430px: 상태·기준일 표시, 가로 넘침 없음, 페이지 오류 없음. 합성 자산만 사용하고 외부 Firebase 요청 차단.
- 운영 조회 시 기존 가격표는 2026-10-26T23:56:57Z 생성, KRX·US 10/26, FX 10/23. 로컬 실제 생성은 KRX 4,308개·US 이전 유효값 24개·FX 10/26(1321.760009765625)을 부분 발행했다. US 수집 지연으로 전체가 실패하지 않음을 확인했다.
